# theapplockr.com

The public marketing site for The App Lockr, an Android app locker by Ubersoft LLC. It is static HTML/CSS/JS with no build step, hosted on GitHub Pages from `main` (root). The custom domain is set in `CNAME` (theapplockr.com), and `.nojekyll` is present so files are served verbatim.

## Source of truth and publishing

The editable copy lives in `theapplockr-dev/site/`; changes are made there and published here by the auditor (`theapplockr-dev` `tools/build.bat` does not publish). Publishing must copy files over this repo without deleting files that only exist here: `README.md`, `.gitignore`, `CHANGELOG.md`. Merging to `main` deploys immediately — every PR needs a DevOps security check and QA before the CEO merges; record each change in `CHANGELOG.md`.

Do not rename or remove live paths: they are linked from Google Play, search results and social shares.

## Files kept on purpose

- `assets/theapplockr-fgs-demo.mp4` is not linked from any page but is the public demo video for the Play Console foreground-service (`FOREGROUND_SERVICE_SPECIAL_USE`) declaration — keep it at this URL.
- `assets/img/app-icon-512.png` is currently identical to `app-icon.png` and unreferenced by the pages; it is regenerated by `theapplockr-dev` `tools/scripts/make-store-art.mjs` on every art run, so remove it there first if it is ever retired.

## Third parties

The only external resource is GoatCounter (`theapplockr.goatcounter.com`, script from `gc.zgo.at`) for cookie-less page-view counts, as disclosed in `privacy.html`; everything else is self-hosted.
